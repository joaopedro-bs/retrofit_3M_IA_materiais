**A Problem-Centric Ontology-Driven Framework for Grounding Large Language Models in Enterprise Financial Knowledge** — S Lunyakin (2026)
- Tese central: Um framework estruturado para aterramento (grounding) de LLMs em bases de conhecimento financeiro corporativo usando ontologias.
- Método: Engenharia de ontologias e framework de 6 etapas avaliado com dados financeiros corporativos.
- Principal achado: Ontologias estruturadas mitigam o cold start de bases desestruturadas e oferecem maior confiabilidade e explicabilidade no uso de LLMs.
- Relevância para o 3M 5.0: Model (framework de ontologia para grounding) / Contexto (uso corporativo em finanças)
