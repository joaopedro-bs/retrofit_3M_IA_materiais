**Automated data science project knowledge graph construction using a document retrieval augmented generation pipeline** — A. Kumarasinghe, M. Kirikova (2025)
- Tese central: Automatizar a construção de grafos de conhecimento de projetos de ciência de dados através de pipelines de RAG a partir de documentos de projetos.
- Método: Implementação e teste experimental de pipeline automatizado para extração de entidades e relações a partir de relatórios.
- Principal achado: Ferramentas baseadas em RAG reduzem drasticamente o tempo manual de criação de grafos sem comprometer a exatidão das conexões estruturadas.
- Relevância para o 3M 5.0: Model (automação na ingestão de novos conhecimentos na UC)
