**An Efficient Retrieval-Augmented Hybrid Search Framework with LLM-Based Re-ranking for Enterprise Knowledge Systems** — s. paidi (2026)
- Tese central: Desenvolver um framework híbrido de busca RAG eficiente, integrando busca vetorial, busca lexical e re-ranking por LLMs para o contexto empresarial.
- Método: Desenvolvimento algorítmico e avaliação experimental em base de dados corporativa de larga escala.
- Principal achado: A arquitetura em dois estágios (recuperação híbrida rápida + re-ranking focado) eleva a precisão das respostas sem sobrecarregar a latência.
- Relevância para o 3M 5.0: Model (arquitetura híbrida otimizada para o EKM da UC) / Moment (eficiência e respostas rápidas)
