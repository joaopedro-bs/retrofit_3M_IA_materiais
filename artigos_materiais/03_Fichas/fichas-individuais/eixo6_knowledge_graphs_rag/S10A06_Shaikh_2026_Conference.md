**Secure Retrieval-Augmented Generation Framework for Automated Knowledge Access in Enterprise Git Repositories** — W. Shaikh et al. (2026)
- Tese central: Propor um framework de RAG seguro e otimizado para recuperação e síntese de conhecimento a partir de repositórios Git corporativos.
- Método: Desenvolvimento e teste de um assistente de código com controle de acesso integrado a nível de documento.
- Principal achado: É possível prover respostas integradas sobre múltiplos repositórios respeitando de forma rígida as permissões de acesso de cada usuário.
- Relevância para o 3M 5.0: Model (busca semântica em repositórios de desenvolvimento) / Governança (controle de privilégios de acesso na UC)
- Acesso: PAYWALL
